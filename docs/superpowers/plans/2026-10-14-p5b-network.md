## 与参照的三处语义差异（记 MAPPING §14）

1. **端口转发用 `adb forward`/`reverse` 代替 netsh portproxy。** spec §3 第 239 行明写。参照的 `port_proxy.rs` 整个是 `netsh interface portproxy`——WSA 侧不适用。
2. **防火墙那条 netsh 规则保持不变**（spec 同一条：结构照搬，只是转发机制换）。`firewall.rs` 照搬。
3. **HTTP 代理用 `settings put global http_proxy`**（spec §1 第 116 行实测），参照用的是给 WSL 导 `HTTP_PROXY` 环境变量——那套在 WSA 上没有意义。

## Review Focus

1. **`reverse` 的 serial 列是主机名不是 `serial:port`** —— 一个按 `forward` 格式写的解析器会把每条 reverse 规则都丢掉，页面显示空而实际有规则。→ Task 1 `reverse_list_accepts_a_host_name_in_the_serial_column`。
2. **端口解析失败必须丢弃而不是归 0** —— 端口 0 的规则不是规则，页面会让用户去删一个不存在的东西。→ Task 1 `a_port_that_is_not_a_number_is_dropped_not_zeroed`。
3. **重转发同一本地端口是替换不是追加** —— 否则列表出现两条，用户以为建了两条其实后一条盖了前一条。→ Task 1 `re_forwarding_the_same_local_port_replaces_rather_than_duplicates`（替身建模）。
4. **`settings put global http_proxy` 关掉时必须写空值** —— Android 的 `settings put global http_proxy :0` 才是"无代理"，留一个旧值等于没关。→ Task 2。
5. **`adb forward` 改的是宿主侧监听，WSA 停止后仍然有效** —— 这一页在子系统关闭时也要能读（和磁盘页同理由）。→ 域层不依赖 `probe`。

  pub async fn reverse_remove(&self, device: u16) -> Result<(), OpsError>;

  pub async fn reverse_list(&self) -> Result<Vec<PortMapping>, OpsError>;

- [ ] **Step 1: 写失败的测试**（八个，加在 ops.rs 的 `mod tests`）

两个纯函数测试各测：实测形状+丢垃圾行、reverse 主机名、空输入、非数字端口丢弃、以及三条 `#[tokio::test]` 回环（forward add→list→remove→list 空、reverse 同、重复 forward 是替换）。

- [ ] **Step 2: 跑测试确认失败**

Run: `cargo test --release --bin wsadash port` / `forward` / `reverse`
Expected: 编译失败，`cannot find function parse_forward_list`。

- [ ] **Step 3: 实现解析器与六个操作**

`parse_forward_list` / `parse_reverse_list` 共用一个 `parse_port_mappings(stdout)` 内核：按行 split_whitespace 取三段（serial、`tcp:<local>`、`tcp:<remote>`），`tcp:` 前缀剥掉、非数字或缺失则 `continue`。serial 原样保留（`forward` 是 `127.0.0.1:58526`、`reverse` 是 `host-16`，两个解析器因此完全一样——差异只在文档，不在代码）。

六个 op 各跑一个 `WsaCommand` 并 `require_success`；list 两个跑命令后过解析器。

- [ ] **Step 4: 替身 adb 加 forward/reverse 分支**

`BATCH` 里加 `:forward` / `:reverse` 标签，维护 `forward.txt` / `reverse.txt`（`add` 追加或替换同 local 行、`--remove` 删该行、`--list` type 出来）。照 `:apply` 已有的"无括号 + goto"结构写，避开括号块里 `%VAR%` 提前展开的坑。`FakeAdb::new()` 预建两个文件。
